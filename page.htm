Basics of HTML

HTML is a Hyper Text Markup Language. It stands for "Hyper Text Markup Language". It is firstly invented in 1989 by "Tim Berners Lee" after the invention of www. It is used for the structuring of the webpage. In other words, we can say that it is the skeleton of the webpage.The extension name of html is .htm or .html. So its very easy to create a html file, you just need to put the extention name back of the file name (i.e. myfile.html)
It gives the information about a lots of elements in the webpage.

Some elements of the webpage that can be improvised through the html are mentioned below:
(a) font-size,
(b) font-style,
(c) text-alignment,
(d) text-color,
(e) background-color, etc,.

Note:

The important thing to notice here is that every element start with a <"tag-line"> and ends with a <"/tag-line> (using slash / to end)

Structure of HTML

For implementing any form of code or language has there own way of presenting it. Every language has to be conveyed in a particular manner and style. Thus from the above discussions, it should be clear by now that HTML also have his own way or stucture of writing.
So now we'll be discussing about its structure below:

<"!Doctype html">

<"html">

<"head">
<"title">{title of the page}<"/title">
<"/head">

<"body">
{body of the webpage}
<"/body">

<"/html">
